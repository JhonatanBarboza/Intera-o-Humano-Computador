# Como executar os wireframes de alta fidelidade

## Opção 1 — Python (já vem instalado no Linux/Mac)

```bash
cd "Wireframes de alta fidelidade"
python3 -m http.server 8642
```

Acesse: [http://localhost:8642/index.html](http://localhost:8642/index.html)


## Opção 2 — Node.js (via npx, sem instalar nada globalmente)

```bash
cd "Wireframes de alta fidelidade"
npx --yes serve -l 8642
```

Acesse o endereço que aparecer no terminal (por padrão [http://localhost:8642](http://localhost:8642)).
