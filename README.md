# Interação Humano-Computador

**Patas que Acolhem** — protótipo de uma plataforma web que centraliza a divulgação de animais para adoção de múltiplas ONGs/abrigos, permitindo que adotantes busquem e filtrem animais e que cada instituição gerencie seus cadastros e sua página institucional. Projeto da disciplina de Interação Humano-Computador.

- [`Docs/`](Docs) — pitch, personas e jornadas do usuário
- [`Wireframes/`](Wireframes) — wireframes de baixa fidelidade
- [`Wireframes de alta fidelidade/`](Wireframes%20de%20alta%20fidelidade) — protótipo navegável de alta fidelidade (HTML/CSS/JS estático, sem backend). Comandos para rodar: [Wireframes de alta fidelidade/README.md](Wireframes%20de%20alta%20fidelidade/README.md)
